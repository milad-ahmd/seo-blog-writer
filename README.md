## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- seo-blog-writer
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/seo-blog-writer /tmp/seo-blog-writer
mkdir -p ~/.claude/skills && cp -r /tmp/seo-blog-writer/skills/seo-blog-writer ~/.claude/skills/
```

**Per project:** copy `skills/seo-blog-writer` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/seo-blog-writer/SKILL.md) into your rules or system prompt.

## 💬 Usage
